# 🐬 Dolphin SMS

پنل پیامکی هوشمند + فروشگاه آنلاین + ربات چندپیام‌رسانه

## 🌟 امکانات

### 🏪 پنل مغازه‌دار (`/panel/login`)
- 📤 ارسال پیامک (MCI / آموت)
- 📞 مدیریت مخاطبین و گروه‌ها
- 📄 قالب‌های آماده پیامک
- 💰 کیف پول و شارژ
- 🎫 سیستم تیکت پشتیبانی
- 🎁 باشگاه مشتریان و امتیاز
- 🎯 سیستم دعوت دوستان
- 📊 گزارش‌های جامع
- 🤖 مدیر AI
- 📢 تبلیغات ربات
- 🎨 قالب‌های پوستر
- 📨 گزارش پیام‌ها با فیلتر وضعیت

### 🔐 پنل ادمین (`/admin/login`)
- 👥 مدیریت کاربران (افزودن، توقف، شارژ)
- 📊 داشبورد آماری
- 💳 گزارش درآمد و پرداخت‌ها
- 🎫 تیکت‌ها
- 🎁 باشگاه مشتریان
- 🎂 تولدها
- 🤖 مدیریت ربات‌ها
- 🌐 تنظیم URL عمومی

### 🛒 پنل مشتری (`/customer`)
- 📱 ثبت‌نام با شماره موبایل
- 🔍 جستجوی زنده مغازه و محصول
- 🛍️ سبد خرید چند فروشگاهی
- 📦 پیگیری سفارش
- ⭐ امتیاز و نظرسنجی
- 🔔 اعلان‌ها
- 💬 چت با مغازه‌دار

### 🤖 ربات‌های پیام‌رسان
- ✅ روبیکا، تلگرام، بله، سروش، ایتا
- 🤖 چت‌بات AI (Pollinations)
- 🎨 عکس‌ساز AI
- 🔗 Force-Join
- 💬 چت ناشناس
